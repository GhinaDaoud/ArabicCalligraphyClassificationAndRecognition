# Methodology and Experiments

## Methodology

This study addresses single-label Arabic calligraphy style classification over seven classes (Diwani, Kufic, Muhaqaq, Naskh, Nasta'liq, Ruq'ah, and Thuluth) under practical constraints of limited computation and high visual variability in the source data. The methodological design was driven by three dominant risks observed during data analysis: a long-tailed class distribution, large differences in image resolution and aspect ratio, and potential data leakage caused by duplicate or near-duplicate samples distributed across multiple sources. To control these risks, the pipeline was designed as a sequence of explicit stages: duplicate-aware data curation, leakage-safe splitting, resolution-preserving preprocessing, and class-imbalance-aware model optimization.

The starting point was a cleaned inventory of 8,046 samples. A unified manifest was then built by joining cleaned sample metadata with image-level statistics and pHash-based duplicate relations. Instead of treating samples independently, each image was assigned a duplicate-aware group identifier derived from connected components in a duplicate graph, where edges were formed from both near-duplicate pHash matches and exact pHash equality. This produced 7,876 groups and allowed split assignment at group level rather than image level, which is essential to prevent optimistic evaluation caused by hidden duplicate leakage.

Using these groups, the dataset was partitioned into training, validation, and test subsets with a 70/15/15 ratio (5,633, 1,207, and 1,206 samples, respectively). Overlap checks between splits confirmed zero shared groups across all split pairs. This ensures that visually near-identical samples never appear in different evaluation partitions and that reported results reflect true generalization rather than memorization of repeated patterns.

Because the original images span a wide range of resolutions, direct square resizing was avoided to reduce geometric distortion and loss of style-defining stroke information. Preprocessing therefore followed a content-aware procedure: foreground-centered cropping to remove empty margins, aspect-ratio-preserving resizing, and symmetric padding to a fixed rectangular canvas. The selected operating resolution was 224x448 (height x width), chosen as a compromise between computational feasibility and visual fidelity for elongated calligraphic structures. This preprocessing stage completed successfully for all splits with zero failed files.

For classification, EfficientNet-B0 pretrained on ImageNet was selected as the final backbone due to its favorable accuracy-efficiency balance in constrained settings. The classifier head was replaced with a lightweight dropout-plus-linear layer targeting the seven calligraphy classes. To address class imbalance during optimization, two complementary mechanisms were used: weighted sampling with weights proportional to the inverse square root of class frequency and effective-number weighted cross-entropy with \(\beta=0.999\). This combination increases minority-class exposure during training while retaining all available samples.

Training was conducted in two stages. In the warmup stage, the feature extractor was frozen and only the classifier head was optimized; in the fine-tuning stage, the last backbone blocks were unfrozen for task-specific adaptation. Optimization used AdamW with mixed-precision acceleration and early stopping. Model selection was based primarily on macro-F1 rather than accuracy, so that class-balanced performance dominated checkpoint choice. This selection criterion was important because overall accuracy can be inflated by majority classes in imbalanced settings.

## Experiments

All experiments were executed with the same leakage-safe split and the same preprocessing policy (224x448), so that differences in performance are attributable to training configuration rather than data partition changes. Two runs were retained for comparison: a baseline EfficientNet-B0 configuration and a tuned configuration with reduced head learning rate, adjusted stopping patience, and extended fine-tuning duration.

The baseline run achieved a validation macro-F1 of 0.8924 and a test macro-F1 of 0.9088, with test accuracy of 0.9287. The tuned run improved validation macro-F1 to 0.9053 and test macro-F1 to 0.9399, with test accuracy of 0.9561. Relative to baseline, this corresponds to gains of +0.0129 in validation macro-F1, +0.0312 in test macro-F1, and +0.0274 in test accuracy. These improvements indicate that optimization-level tuning materially improved generalization without introducing architectural complexity beyond the selected backbone.

Class-wise analysis of the tuned model on the test set showed consistently high recall: Diwani 0.918, Kufic 0.930, Muhaqaq 0.967, Naskh 0.970, Nasta'liq 0.959, Ruq'ah 0.987, and Thuluth 0.933. The relatively uniform recall profile across both majority and minority classes supports the effectiveness of the combined imbalance strategy. In particular, minority classes did not collapse under majority dominance, which was a key design objective from the outset.

The final selected checkpoint is the tuned EfficientNet-B0 model. Given the dataset characteristics and compute limits, it provided a robust and reproducible operating point and is therefore adopted as the final model for reporting and downstream use.
